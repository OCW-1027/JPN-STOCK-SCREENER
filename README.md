# Multi-Market Screener v3 — 일본·한국·미국 / 한국어·日本語

한 사이트에서 3개 시장 × 2개 언어. GitHub Actions가 각 시장 장중 15분 간격으로 자동 갱신.

## 페이지 주소
| | 한국어 | 日本語 |
|---|---|---|
| 일본 | `/jp/` | `/ja/jp/` |
| 한국 | `/kr/` | `/ja/kr/` |
| 미국 | `/us/` | `/ja/us/` |

우측 상단 버튼으로 언어 전환(현재 보던 시장 유지). 일본 친구에게는 `/ja/jp/` 주소를 그대로 공유하면 됩니다.

## v3 변경점
1. **상단에도 가로 스크롤바** — 표 위/아래 어디서든 좌우 이동, 서로 동기화
2. **표시 항목 프리셋** — `테크니컬 / 재무 / 전체` 버튼으로 컬럼을 갈아끼움 (가로 스크롤 자체를 줄이는 게 핵심)
   - 가치·펀더 탭을 누르면 재무 프리셋으로 자동 전환
3. **사업내용 한국어화·상세화** — `섹터 · 세부업종` 130개 업종 전부 번역 (예: 반도체·전자 생산장비, 트럭·건설·농기계).
   한국은 여기에 KRX 주요제품이 덧붙음 (예: `전자·반도체 · 반도체 — 통신 및 방송 장비 제조(무선), 반도체(메모리)...`).
   셀에 마우스를 올리면 전문 표시.
4. **일본어 전체 페이지** — UI·업종·시그널명 모두 일본어 (シグナル: 出来高急増/パーフェクトオーダー/割安 등)
5. **모바일 대응** — 세로: 고정열 폭 축소·터치 스크롤 / 가로: 헤더와 업종 스트립을 접어 표를 최대화

## 파일 (4개 — i18n.py가 새로 추가됨)
- `screener.py` 수집·시그널·페이지 생성
- `template.html` 화면
- `i18n.py` **신규** — 한/일 UI 문구 + 130개 업종 번역 사전
- `requirements.txt`, `.github/workflows/daily.yml` (변경 없음)

## 리포 반영
`screener.py` · `template.html` · `i18n.py` 3개를 리포 루트에 업로드(덮어쓰기) → Actions에서 Run workflow.
daily.yml은 그대로 두면 됩니다.

## 시그널 (13종)
단기: 급증 / 5MA·20MA돌파 / 신고가권 / 갭업 / 과매도반등
중장기: GC직후 / 200탈환 / 정배열 / MACD골든
가치·펀더: 저평가(PER≤10&PBR≤1) / 고배당(4%↑) / 우량(ROE≥15&자기자본≥50)
임계값은 `screener.py` 상단 CONFIG에서 조정.

## 한계
- 회사별 서술형 사업 소개(문장)는 무료 데이터에 없어 업종 기반 표기입니다. 문장형이 필요하면 별도 유료 데이터나 주 1회 프로필 캐시 방식이 필요합니다(v4 후보).
- 지표는 스냅샷 기반 근사치이며 투자 판단·책임은 본인에게 있습니다.

## v6 추가 (2026-08-19)
1. **회사별 서술형 사업 소개** — 사업내용 셀 클릭 → 회사 소개 전문이 행 아래로 펼쳐짐.
   야후 프로필(영문)을 시총 상위부터 종가판마다 250건씩 자동 수집·누적 (`profiles.py`, `profiles/{m}.json.gz`).
   2~4주면 전 종목 완성, 이후 180일 주기 갱신. 미수집 종목은 안내 문구 표시.
2. **TDnet 적시공시 탭 (일본)** — 오늘+전영업일 공시를 키워드 12종(상방수정·자사주·TOB·분할 등)으로 태깅.
   키워드 칩 필터·행 클릭→PDF, 강한 재료(상방·증배·자사주·분할·TOB)는 메인 표 시그널 칸에 `공시` 마커.
   소스: TDnet 비공식 API(yanoshin) — 중단 시 빈 목록으로 폴백.
3. **시그널 성과 백테스트** — `backtest.py`가 history 스냅샷으로 시그널별 +1/5/20일
   승률·평균수익·시장대비 초과수익을 집계해 `/backtest/` 리포트 생성 (상단 📊 성과분석).
   스냅샷 2일차부터 +1일 통계, 21일차부터 +20일 통계. 데이터 부족 시 축적 안내 표시.
4. v5 포함: 미국 주가 소수점 2자리 고정, %는 값 크기에 따라 자동 정밀도(작을수록 2자리).
