# Multi-Market Screener — 일본 · 한국 · 미국 전 종목 데일리 스크리닝

한 사이트에서 상단 탭(🇯🇵 일본 / 🇰🇷 한국 / 🇺🇸 미국)으로 세 시장을 오가며 봅니다.
GitHub Actions가 각 시장 장중에 15분 간격으로 자동 갱신하고 GitHub Pages로 배포합니다.

## 페이지 구성
- `https://<아이디>.github.io/<리포명>/` → 일본으로 자동 이동
- `/jp/` 일본 (도쿄증권거래소 약 3,800종목, JPX 일본어 종목명·33업종·프라임/스탠다드/그로스)
- `/kr/` 한국 (코스피·코스닥 약 2,700종목, 한글 종목명 — FinanceDataReader)
- `/us/` 미국 (NYSE·나스닥·AMEX 약 5,200종목, 우선주·SPAC유닛 제외)

## 자동 갱신 스케줄 (daily.yml)
| 시간(한국·일본 기준) | 대상 | 비고 |
|---|---|---|
| 평일 09:00~15:45, 15분 간격 | 3개 시장 전체 재생성 | 일본·한국 장중 |
| 평일 16:30 | 〃 + **일본·한국 history 저장** | 종가 확정판 |
| 평일 밤 22:00~익일 05:45, 15분 간격 | 3개 시장 전체 재생성 | 미국 장중 |
| 평일 아침 06:30 | 〃 + **미국 history 저장** | 미국 종가 확정판 |

- 매 실행은 세 시장을 모두 새로 만들어 통째로 배포하므로 페이지 간 불일치가 없습니다.
- 장중 실행은 리포에 커밋을 남기지 않고, 종가판만 `history/jp|kr|us/날짜.csv.gz`를 커밋합니다.
- 미국 서머타임 전환은 cron 창을 넓게 잡아 흡수합니다 (겨울철 마지막 15분은 종가판이 커버).

## 시그널 (전 시장 공통, screener.py CONFIG에서 조정)
단기: 급증(RVOL≥2.5) · 5MA/20MA 당일 돌파 · 신고가권(52주 고가 98%↑) · 갭업(+3%↑)
중장기: GC직후 · 200일선 탈환 · 정배열(과열 제외)
거래대금 하한(기본: 1억엔 / 1억원 / $1M)은 각 페이지 안에서 변경 가능.

## 로컬 실행
```bat
pip install -r requirements.txt
python screener.py     # site/ 생성 후 일본 페이지 자동 오픈
```

## 리포 반영 방법 (기존 JPN-STOCK-SCREENER 업그레이드)
1. 루트에 `screener.py` `template.html` `requirements.txt` `README.md` 드래그 업로드 (덮어쓰기 커밋)
2. `.github/workflows/daily.yml` 열어 ✏️ 편집 → 전체 교체 붙여넣기 → 커밋
3. Actions → Daily Screener → Run workflow → 성공 후 `/jp/` `/kr/` `/us/` 확인
(Pages Source는 이미 GitHub Actions로 설정되어 있으므로 추가 설정 없음)
